# Binary Representation with One Pair of Consecutive Set Bits

**Difficulty:** Easy

## Problem Statement

You are given an integer `n`.

Return `true` if its binary representation contains exactly one pair of consecutive set bits, and `false` otherwise.

## Examples

**Example 1**
```
Input:  nums = 6
Output: true
Explanation: Binary of 6 is "110". There is exactly one pair of consecutive set bits ("11").
```

**Example 2**
```
Input:  nums = 5
Output: false
Explanation: Binary of 5 is "101". There are no consecutive set bits.
```

## Constraints

- `0 <= n <= 10^5`
